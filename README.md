# 🌐 Personal Portfolio

🚀 Live Demo: https://portfolio-prathvik.netlify.app/

## 📌 About The Project

This is my personal portfolio website built using **React**, designed to showcase my projects, skills, and experience as a developer.

It highlights my work, technical abilities, and provides an easy way to connect with me.

---

## ✨ Features

* 🎯 Modern and clean UI
* 📱 Fully responsive (mobile, tablet, desktop)
* 📂 Project showcase section
* 🧠 Skills and technologies display
* 📬 Contact section
* ⚡ Fast and optimized performance

---

## 🛠️ Tech Stack

* **Frontend:** React.js
* **Build Tool:** Vite
* **Styling:** CSS / Tailwind *(update if needed)*

## ⚙️ Getting Started

### 1. Clone the repository

```
git clone https://github.com/Prathvikmehra/Portfolio.git
cd Portfolio/project
```

### 2. Install dependencies

```
npm install
```

### 3. Run locally

```
npm run dev
```

### 4. Build for production

```
npm run build
```

## 🚀 Deployment

The project is deployed on **Netlify** with continuous deployment enabled.

Any changes pushed to the `main` branch are automatically built and deployed.
