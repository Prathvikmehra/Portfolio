# 🌐 Premium Personal Portfolio

## 📌 About The Project

This is a **High-End, Premium Portfolio** built with **React** and **Framer Motion**, featuring a cinematic olive-green aesthetic and deep interactive depth. It is designed to showcase technical mastery while providing a luxurious user experience.

---

## ✨ Features

*   **💎 Premium Aesthetic**: Tailored "Olive-Green" theme with glassmorphism, noise textures, and smooth radial gradients.
*   **🎡 Infinite Arcade Zone**: A high-performance horizontal marquee showcasing mini-games (Color Guesser, Typing Speed, etc.) with real-time descriptions.
*   **💊 Interactive Floating Navbar**: Capsule-style navigation with animated tooltips for all icons, including a real-time IST clock and prestigious Medal icon.
*   **🚀 Dynamic Hero Section**: Smooth typing animations for professional roles and a rotating "Available for Hire" badge.
*   **📱 Responsive Grid Layout**: Clean, organized grid-based cards for primary project clones (Cantabil, Stanley, Cuts).
*   **⚡ Optimized Performance**: Built on Vite with industry-standard Framer Motion animations.

---

## 🛠️ Tech Stack

*   **Frontend Framework:** React.js
*   **Build Tool:** Vite
*   **Animations:** Framer Motion
*   **Styling:** Vanilla CSS (Modern CSS Variables & Custom Typography)
*   **Deployment:** Netlify

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Prathvikmehra/Portfolio.git
cd Portfolio/project
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run locally

```bash
npm run dev
```
